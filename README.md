# Guía de MyTechPix de KEC — Español

Spanish version of the KEC MyTechPix Guide for techs: what to capture, when to capture it, and how to avoid QA blocks. Blue / Green / Red shown as Azul (Blue) / Verde (Green) / Rojo (Red).

- Live (English): https://mytechpix-guide-for-techs.netlify.app/
- This site: Spanish, 21 slides, 5-question quiz (need 4 to pass).
- Read-aloud: Spanish speech synthesis, rate 0.75, 600 ms pause between bullets/sentences. The English recording is not used in this version.
- Language toggle in the top bar links back to the live English site.
